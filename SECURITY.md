# Security Policy

## Reporting a vulnerability

Please report security issues through GitHub private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**.
Do not open a public issue for a suspected vulnerability.

Include the affected version or commit, steps to reproduce, and the impact you
observed. You can expect an acknowledgement within a few days. Fixes are
released as soon as they are verified, and reporters are credited if they wish.

## Supported versions

Only the latest release and the `main` branch receive security fixes.
